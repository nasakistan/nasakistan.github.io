**1. Processamento Inteligente de Documentos (IDP)**

* **Tags:** `UiPath`, `Document Understanding`, `IDP`, `Machine Learning`

**2. Sistema de Fila Virtual e Gestão**

* **Descrição:** Plataforma web completa desenvolvida para o gerenciamento inteligente de atendimento acadêmico e apoio operacional das equipes de suporte.

**3. Automação de Comunicação (WhatsApp)**

* **Descrição:** Sistema automatizado para disparo de notificações e atendimento ao cliente via WhatsApp, aumentando drasticamente a taxa de engajamento e eficiência operacional.

**4. News Web Scraping API**

* **Descrição:** API RESTful robusta desenvolvida em Express e Cheerio para extração e estruturação em tempo real de matérias de grandes portais de notícias, alimentando um front-end dinâmico.
* **Tags:** `Node.js`, `Express`, `Web Scraping`, `APIs`

## 🎨 Sobre o Projeto Void Room

O **Void Room Portfolio** é uma experiência web minimalista e hiper-estilizada. O projeto apresenta o perfil profissional de forma imersiva em um ambiente 3D escuro com grade em perspectiva, iluminação animada em tons de roxo, efeitos de *glassmorphism* e cores *rainbow* com destaque para o espectro violeta.
